# QR Code Generator

A simple, responsive QR Code Generator built using **HTML, CSS, and JavaScript**.  
It allows users to generate QR codes from text or URLs, choose the output size, and download the generated QR code as an image.

---

## Live Demo

```
https://qrgenerator-viraljain.netlify.app/
```

---

##  Features

- Generate QR codes from any text or URL  
- Multiple size options (64×64, 128×128, 256×256, 512×512)  
- Download QR code as a PNG image  
- Clean, modern UI with responsive design  
- Instant generation using client-side JavaScript  

---

##  Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & responsiveness  
- **JavaScript (Vanilla)** – Logic & interactivity  
- **QRCode.js** – QR code generation library  

---

##  Project Structure


---

##  How It Works

1. User enters text or a URL  
2. Selects the desired QR code size  
3. Clicks **Generate** to create the QR code  
4. Clicks **Download** to save it as a PNG image  

All processing happens on the client side—no backend required.

---

##  Installation & Usage

1. Clone the repository:

```
git clone https://github.com/ViralJain758/QR-Code-Generator.git
```

2. Open `index.html` in your browser.

That’s it. No build tools, no dependencies to install.
